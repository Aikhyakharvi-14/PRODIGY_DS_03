# PRODIGY_DS_03
This project predicts loan approval status using a Decision Tree Machine Learning model.The dataset contains applicant demographic and financial details. The workflow includes data preprocessing, model training, prediction, evaluation, and visualization.

Features:
Data Cleaning
Missing Value Handling
Label Encoding
Train-Test Split
Decision Tree Classification
Accuracy Evaluation
Tree Visualization

Technologies Used:
Python
Google Colab
Pandas
Scikit-learn
Matplotlib

Output:
Loan Approval Prediction
Model Accuracy
Decision Tree Visualization
